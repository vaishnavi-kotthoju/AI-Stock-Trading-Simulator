# AI Stock Trading Simulator

An AI-powered stock market analytics and automated trading simulator
built with Machine Learning and Technical Indicators.

## Features
- Real stock data via Yahoo Finance
- Technical indicators (MA20, MA50, Volatility, Daily Return)
- Random Forest ML model for BUY/SELL/HOLD signals
- Virtual trading simulator with P&L tracking
- Interactive Streamlit dashboard

## Tech Stack
Python, Pandas, Scikit-learn, Streamlit, Plotly, YFinance

## Results
- Starting Balance : 1,00,000
- Final Balance    : 4,89,337
- ROI              : 389%
- Total Trades     : 60

## How to Run
pip install -r requirements.txt
streamlit run dashboard/app.py
